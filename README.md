# maksimovic/zend-json

A PHP 8.1+ compatible fork of [zf1s/zend-json](https://github.com/zf1s/zend-json), originally from [Zend Framework 1](https://github.com/zendframework/zf1).

JSON encoding/decoding with a JSON-RPC server implementation. Supports JSON expressions and XML-to-JSON conversion.

## Installation

```bash
composer require maksimovic/zend-json
```

This package replaces `zf1/zend-json` and `zf1s/zend-json`.
